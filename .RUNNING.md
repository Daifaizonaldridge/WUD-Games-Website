# Running WUD Games locally

From the repository folder, start Docker Desktop and run:

```powershell
npm run server
```

Open <http://localhost:8080>. The first startup can take a few minutes while Ollama downloads its models. Press **Ctrl+C** in that terminal to stop the web app, then run `npm run stop` to stop PostgreSQL and Ollama. Database files and downloaded models are retained in `database/data/`.

`npm run server` creates the private `config/.env` from `config/.env.example` on first run. Edit that file to configure Google sign-in. The launcher builds the app, starts the services in `database/compose.yaml`, and runs the packaged JAR directly so the Java process stops cleanly without a leftover Maven process.

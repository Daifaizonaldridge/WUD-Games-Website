# Running WUD Games locally (Windows)

Run these commands in PowerShell from the repository root.

## Start

1. Start PostgreSQL and Ollama with Docker Desktop running:

   ```powershell
   docker compose up -d
   ```

2. Set local application settings. The included bcrypt hash is the development password `password`; replace it if you want a different admin password hash.

   ```powershell
   $env:JDBC_DATABASE_USERNAME = 'myuser'
   $env:JDBC_DATABASE_PASSWORD = 'secret'
   $env:DEFAULT_ADMIN_EMAIL = 'example@gmail.com'
   $env:DEFAULT_ADMIN_PASSWORD = '$2a$12$XcmLV3Vkl6/tHwEAzF7uWuIe4HMq2R841x8p6m3.O7hJSoPYsWH7O'
   $env:OAUTH2_GOOGLE_CLIENT_ID = 'local-test-client'
   $env:OAUTH2_GOOGLE_CLIENT_SECRET = 'local-test-secret'
   ```

   The placeholder OAuth values let the app start, but Google sign-in will not work until you use real Google OAuth credentials.

3. Launch Spring Boot:

   ```powershell
   .\mvnw.cmd spring-boot:run
   ```

4. Open <http://localhost:8080>. The first startup may take several minutes while Ollama downloads its models. Keep this PowerShell window open while using the app.

## Stop

- Press **Ctrl+C** in the PowerShell window running Spring Boot to stop the application.
- To also stop PostgreSQL and Ollama, run this from the repository root:

  ```powershell
  docker compose down
  ```

`docker compose down` stops the containers without deleting the database files in `data/pgvector`.

The app's frontend assets are built by Maven; a separate frontend dev server is not required for this startup method.
